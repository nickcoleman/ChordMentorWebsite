# ChordMentor website

Static site for GitHub Pages: `index.html`, `privacy.html`, `support.html`, `style.css` and `images/`. No build step.

Support email: chordmentor@nickcoleman.io (in `support.html`).

To host:
1. Create a public GitHub repository (for example `chordmentor-site`) and push this folder to it.
2. In the repository's Settings › Pages, set Source to "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<your-username>.github.io/chordmentor-site/`.

In App Store Connect, use `…/privacy.html` as the Privacy Policy URL and `…/support.html` as the Support URL.
